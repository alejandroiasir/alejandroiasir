## 📂 Proyectos destacados

### 🖥️ Consulta Inteligente de Solicitudes con IA y MCP

Aplicación desarrollada en Python con integración de IA generativa y MCP para consultar bases de datos MySQL mediante lenguaje natural.

- Consultas en español con acceso de solo lectura a la base de datos mediante herramientas MCP.
- Integración con Make para automatizar el envío de correos, el registro de solicitudes en Google Sheets y la generación de alertas de urgencia.
- Interfaz interactiva para seleccionar y procesar solicitudes con un solo clic.

🔗 Repositorio: [make-mcp-mysql-demo](https://github.com/alejandroiasir/make-mcp-mysql-demo)

### 🤖 Chatbot para Asistencia Virtual Agrícola
Aplicación backend en **Python** con el framework **Haystack** para orquestar pipelines **RAG**.

- Indexación de documentos y recuperación con **búsqueda semántica** sobre una base de datos vectorial.
- Enrutamiento entre herramientas externas: búsqueda web, reconocimiento de imágenes y consulta meteorológica.
- Pruebas para validar los componentes principales del pipeline.

🔗 Repositorio: [agricultural-virtual-assistant](https://github.com/alejandroiasir/agricultural-virtual-assistant)

### 📚 RAG personal sobre documentos locales

Aplicación en **Python** con el framework **Haystack** para responder preguntas sobre tus propios documentos, con citas a los fragmentos de origen. Arquitectura **RAG**. Todo se ejecuta en tu equipo: **Qdrant en modo local y Ollama para los modelos**.

- Indexación de PDF, DOCX, TXT, MD y HTML con búsqueda semántica sobre una base de datos vectorial.
- Respuestas con citas al fragmento usado, y abstención cuando no hay evidencia en los documentos.
- Interfaz web local para subir documentos y hacer preguntas, y evaluación contra un corpus de preguntas con respuesta conocida.

🔗 Repositorio: [personal-rag](https://github.com/alejandroiasir/personal-rag)
